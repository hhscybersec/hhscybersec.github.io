# HHS Cybersecurity Club Website

The official website for the Cybersecurity Club. Built to provide members with resources, meeting notes, and club information.

## Tech Stack

* **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
* **Language:** TypeScript
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Routing:** React Router v6

## Local Dev Setup

To get this project running locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/hhs-cyber-club.git](https://github.com/your-username/hhs-cyber-club.git)
   ```

2. **Navigate into the directory:**
   ```bash
   # Navigate to the folder
   cd hhs-cyber-club

   # Install React dependencies
   npm install

   # Start the development server
   npm run dev
   ```
